登记簿里的故事 Dobra 与 Jurków 堂区

我们村庄里真实的人物故事，读自1678–1926年的洗礼、婚礼和葬礼登记簿。还有神父们在页边补写的内容。

5.4万多条本堂区登记簿记录 近1.7万条来自邻近堂区 登记簿年代为1678–1944年 故事截至1926年 每个故事都附档号和扫描件

哪些登记簿保存了下来、哪些已经辨读，包括邻近的 Mszana Dolna、Niedźwiedź 和 Słopnice 堂区的登记簿：见“登记簿”页 →

    登记簿始于一场大火

    教堂在夜里烧毁，更早的登记簿多半也随之化为灰烬。半个世纪后，一位助理神父趁夜带走了几个月的洗礼记录。

    摘自出版物阅读 →     1678–1839Dobra
    议长、田亩与学校

    Dobra 的学校比 Małachowski 议长的改革还要早。1685年，这所学校的校长为全堂区的孩子们当过教父。

    摘自出版物阅读 →     1678–1923全堂区
    照着日历起名

    叫 Melchior 的人，十个里有九个生在三王节（1月6日）前后。Regina 曾是最受欢迎的女孩名，可1900年以后，登记簿里只有两个。

    新故事阅读 →     1678–1923全堂区
    出生日历

    一月和二月出生的孩子最多，七月和八月最少。直到19世纪中叶，几乎每个孩子都在出生当天或次日受洗。

    新故事阅读 →     1679年起Jurków
    以姓氏命名的小村落

    Siciarze、Czerniki、Szerszenie、Krawce：村里这些地方的名字，来自17世纪登记簿里记载的家族姓氏。

    摘自出版物阅读 →     1682–1943全堂区
    婚礼日历

    超过三分之一的婚礼在二月举行，而260年间十二月只有九场。星期五几乎没有人结婚。

    新故事阅读 →     1683–1927全堂区
    Szczyrzyc 的修士

    早在1683年，就有一位熙笃会修士代理本堂神父。饥荒之年和霍乱肆虐的夏天，是 Szczyrzyc 的修士们为死者下葬；1871年，修道院副院长为弥留之际的本堂神父施行了临终圣事。

    新故事阅读 →     1689–1929Dobra
    Dobra 的管风琴师

    两百多年间，登记簿一直记着 Dobra 的管风琴师。任职最久的是 Mateusz Rudnicki，他既是管风琴师又是教师，是十七个孩子的父亲，也是一位神父的父亲。

    新故事阅读 →     1690–1911全堂区
    别名

    Wojciech Przybytek alias Wójt、Galas alias Fleszar、Węgrzyn recte Gąsior。堂区登记簿里有两个姓的人。

    新故事阅读 →     16世纪–1973Dobra 和 Jurków
    来自 Jurków 的圣像

    Dobra 老教堂的祭坛上挂着一幅画，相传是被洪水冲来的。它原本属于 Mogielica 山下弗拉赫牧人的东正教堂。

    新故事阅读 →     1694–1868Porąbka
    Porąbka：另一座庄园的村子

    在 Dobra，结婚许可由 Dobra 的庄园发放；在 Porąbka，发放许可的却是 Szczyrzyc 和 Janowice 的庄园。这里拥有四分之一份地的农户不多，却有拥有整份地的农户。

    新故事阅读 →     1697–1902Dobra、Wilczyce
    酒馆与掌柜

    Wilczyce 的酒馆掌柜向女庄园主告状，因为本堂神父为他母亲的葬礼牵走了他的牛。堂区登记簿里的酒馆掌柜们，从 Dobra 本地的农民到摩拉维亚来的外乡人。

    新故事阅读 →     1712–1923Dobra、Chyszówki、Półrzeczki、Jurków
    水

    1712年的洪水把一幅圣像从 Jurków 冲走，1825年又卷走了 Chyszówki 16岁的 Anna。在溪流和水井中丧命的，大多是孩子。

    新故事阅读 →     1703–1910全堂区
    双胞胎

    Agnieszka 和 Sebastian、Piotr 和 Paweł、Tomasz 和 Wiktoria：双胞胎常取日历上相邻两位圣人的名字。他们中超过三分之一活不过一岁。

    新故事阅读 →     1726–1732Dobra 及整个 Dobra 领地
    冒尖的量斗

    本堂神父让人做了一个更大的量斗来收弥撒粮。整个领地的农民为此告到克拉科夫的主教法庭，并从那里带回了自己的量斗。

    新故事阅读 →     1730–1922Dobra、Chyszówki
    登记簿里的罗姆人

    1730年，神父为一对罗姆夫妇的儿子施洗，凭另一位罗姆人的话承认了他们的婚姻。孩子的教父是领地的管理人。

    新故事阅读 →     1734–1739Dobra、Jurków、Chyszówki、Zadziele
    四十一条罪状

    Dobra 领地的管家殴打农奴，干了活也不给工钱。1739年，农民和庄园主一起把他告上法庭。受害者中有我在 Jurków 的一位祖先。

    新故事阅读 →     1735Dobra 和 Jurków，Szerszenie
    绿林头领的最后狂欢

    1735年秋，绿林头领 Józef Baczyński 在 Dobra 领地被擒。Jurków 人说，那家酒馆就在 Szerszenie，离今天的小教堂几十米远。

    新故事阅读 →     1774Jurków
    二十年后的婚礼

    Tomasz 和 Agnieszka 已经有了孩子，这时才发现两人是亲戚。主教命他们重新立下婚誓。

    摘自出版物阅读 →     1779–1899全堂区
    目测百岁

    据登记簿记载，Porąbka 的 Zofia Stokłosionka 活到115岁，Stanisław Stokłosa 113岁，Katarzyna Gdowicz 110岁。可 Katarzyna 的结婚记录却另有说法。

    新故事阅读 →     1779–1913全堂区
    房屋编号透露了什么

    登记簿里的编号不是地址，而是房屋建造的先后顺序。1845年，全堂区都换了新编号，而 Jurków 的123号曾属于两座不同的房屋。

    新故事阅读 →     1683–1917全堂区
    磨坊主

    Stokłosa 家族在 Dobra、Jurków 和 Gruszowiec 开磨坊。磨坊主 Piotr Majchrzak 以画十字代替签名，同意了儿子的婚事；一岁半的 Agnieszka 淹死在磨坊的引水渠里。

    新故事阅读 →     1786–1924Gruszowiec
    Gruszowiec 的狼

    1789年，13岁的 Marianna 被狼群撕咬致死；五天前，邻村 Porąbka 7岁的 Paweł 也这样丧命。刚刚辨读完的 Gruszowiec 登记簿，还讲述了饥荒、树和桥的事。

    新故事阅读 →     1799–1920全堂区
    皇帝的士兵

    卡尔大公团的枪骑兵、第57团的列兵、持伤残证书的退伍伤兵、尼达河畔的阵亡者。奥地利军中的乡村子弟，以及他们在登记簿里留下的痕迹。

    新故事阅读 →     1807–1885全堂区
    天花与种痘

    在 Chyszówki 的 Maciej 的洗礼记录下方，有人用德语补写了“Impfung pro 842”，即1842年度种痘。同年4月，这个男孩死于天花，没有种过痘。

    新故事阅读 →     1818–1925Półrzeczki、Chyszówki、Jurków、Dobra
    林中人

    伐木时被树压死的人、从树上摔下的男孩、住在林务所里的波希米亚林务员。堂区登记簿里的森林。

    新故事阅读 →     1820–1900全堂区
    四分之一份地

    父亲姓名旁的“¼ Cm.”，表示从前一户整份地农户（kmieć）田产的四分之一。19世纪中叶，过半数的父亲都是这样登记的。只有 Porąbka 还有拥有整份地的农户。

    新故事阅读 →     1826–1920Jurków、Dobra
    一道闪电

    1826年，一道闪电击死了分属两户人家的一名男子和一个孩子。1920年，Dobra 的神父还记下了一起发生在二月的雷击死亡。

    摘自出版物阅读 →     1826Jurków，Szyrszenie
    Szyrszenie 的小教堂

    我祖先家的对面立着一座建于1826年的小教堂。相传是 Podgórni 家族的一位父亲在儿子当上神父时建的。我在登记簿里寻找过这位神父。

    我的家族阅读 →     1831Jurków，5号房屋
    洗礼池边的伯爵

    我在 Jurków 的祖先有个孩子，教父母是 Małachowski 伯爵和伯爵夫人。这是全堂区唯一一次这样的洗礼。

    我的家族阅读 →     1832–1907全堂区
    未经培训的接生婆

    Agnieszka Chalcarz 接生了739个孩子，Anna Rapacz 接生了300多个。几十年间，登记簿里她们的名字旁一直写着“non examinata”（未经考核）。

    摘自出版物阅读 →     1786–1899全堂区
    寡妇与鳏夫

    超过三分之一的婚礼，新人中有鳏夫或寡妇。鳏夫有时在葬礼一周后就再娶，寡妇却必须等待，这是法律的要求。

    新故事阅读 →     1838Dobra
    Dobra 的林务员

    我的祖先 Józef Przybytek 是庄园的林务员。邻居们每砍一根原木，他就能得七个半克罗伊策。

    我的家族阅读 →     1840–1889堂区四个村
    生命的第一年

    每五个孩子中就有一个活不到一岁生日。最危险的是第一个月，而神父最常写下的只有一个词：虚弱。

    新故事阅读 →     1842Półrzeczki，50号房屋
    匈牙利烟草

    Półrzeczki 的21岁青年 Franciszek 不肯把匈牙利烟草交给守卫边境的士兵。他中弹身亡，被葬在 Krościenko。

    新故事阅读 →     1829–1850Dobra，庄园
    Dobra 庄园的代理官

    1846年3月1日，正值农民暴动，Dobra 庄园的一名官员遇害。神父只写了一句：“因罪行”。他被葬在 Bochnia。

    新故事阅读 →     1847全堂区
    饥荒之年

    Jurków 死了111人，Chyszówki 死了118人，Wilczyce 的死亡人数是平常的九倍。外乡来讨饭的孩子死在了田野里。

    摘自出版物阅读 →     1823–1925全堂区
    经团部同意

    Półrzeczki 的一名士兵得到了军方的许可，他的未婚妻得到了庄园的许可。结婚许可来自利沃夫、匈牙利、Limanowa 的县署，战后则来自波兰的征兵补充司令部。

    新故事阅读 →     1845–1850Dobra、Chyszówki、Wilczyce、Porąbka
    冻死的人

    1848年1月，饥荒之年刚过，严寒在四天之内冻死了三个人。其中两人是乞丐，神父不知道他们的名字。

    新故事阅读 →     1853Chyszówki，51号房屋
    Rakamaz，1853年

    Chyszówki 的一个无地农民死在匈牙利的蒂萨河畔。死讯过了四个月才传回家乡。

    摘自出版物阅读 →     1854/55Dobra、Chyszówki、Półrzeczki、Jurków
    暴雪之冬

    有人被雪闷死，也有病人因积雪太深，神父赶不到身边。这是饥荒年代中的一个冬天。

    新故事阅读 →     1854–1904Dobra、Jurków、Chyszówki
    捷克人与摩拉维亚人

    来自 Červený Kostelec 的道路工长、来自波希米亚的园丁、来自摩拉维亚的护林员，还有一位死在 Jurków 路上的流动阉割匠。

    新故事阅读 →     1855Dobra，99号房屋
    来自维也纳的医生

    一位被派来抗击霍乱的医生死在 Dobra，终年34岁。他身后只留下登记簿里的一条记录。

    新故事阅读 →     1855–1863全堂区
    Józef Rapacz 神父

    1855年霍乱之夏行将结束时，新来的助理神父开始主持葬礼。几周前，一个与他同名同姓的农家儿子刚死于霍乱。

    新故事阅读 →     1860–1893Dobra
    犹太邻居

    Dobra 的本堂神父还把犹太家庭孩子的出生记入洗礼登记簿，其中包括酒馆承租人的孩子。

    新故事阅读 →     1873–1920全堂区
    去俄斯特拉发，去大洋彼岸

    登记簿页边的附注把人引向匈牙利、俄斯特拉发的矿井、普鲁士和芝加哥。还有一位鞋匠从诺曼底来到了 Dobra。

    新故事阅读 →     1873–1941Jurków，78号房屋
    来自 Jurków 的议员和乡长

    Michał Łaskuda 当过 Jurków 的村长和三届议会的议员，他的兄弟 Szymon 是 Dobra 乡的首任乡长。Szymon 于1941年死于布痕瓦尔德集中营。

    新故事阅读 →     1873Zadziele 及全堂区
    Zadziele 的1873年

    堂区最小的村子一年里死了14个人。天花夺走孩子，一位母亲死于产后，而在 Dobra，霍乱三天内在同一户人家夺去了三条人命。

    新故事阅读 →     1786–1896全堂区
    死于分娩

    45岁前去世的已婚妇女中，几乎每五人就有一人死于分娩或产后不久。神父写得很简短：propter partum（因分娩）。

    新故事阅读 →     1883–1901Dobra、Porąbka、Półrzeczki
    铁路与蒸汽锯

    来自贝卢诺的石匠、来自蒂罗尔的监工、来自波希米亚的建筑工头，还有在乡村婚礼上当证婚人的建筑师们。铁路就这样来到了 Dobra。

    新故事阅读 →     1892–1953Jurków，108号房屋
    Jurków 的 Leon 神父

    我的家族确实出过一位神父，只是比那座小教堂晚了一百年。Jurków 的 Andrzej Podgórni 成了道明会士，1944年在 Podkamień 修道院遇袭时奇迹般地幸存。

    我的家族阅读 →     1892–1916邻近的 Mszana Dolna 堂区
    去佩斯，去芝加哥

    在邻近的 Mszana Dolna 堂区，20年间有19名男子死在匈牙利，二十多个孩子出生在布达佩斯。1907年以后，登记簿里出现了芝加哥。

    新故事阅读 →     1892–1904邻近的 Mszana Dolna 堂区
    猩红热、痢疾、麻疹

    1892年夏天，Kasinka Mała 的孩子们开始接连死去。十二年间，猩红热、痢疾、麻疹、白喉和百日咳相继席卷 Mszana Dolna 堂区的各个村庄。

    新故事阅读 →     1894–1912邻近的 Mszana Dolna 堂区
    森林、锯木厂与水

    “在林中丧命”“死在锯木厂”“被牛致死”“被蛇咬伤”。从1897年起，Mszana Dolna 的神父们开始用波兰语记录死因。

    新故事阅读 →     1895–1965Dobra，202号房屋
    酒馆掌柜的外孙

    1895年，Dobra 一位酒馆掌柜的家中诞生了一个男孩，他后来成了捷克斯洛伐克军团士兵、情报军官和驻意大利公使。登记簿里补记了他的死亡地点。

    新故事阅读 →     1895–1906Mszana Górna，邻近堂区
    25号的曾祖母

    一位寡妇、四个成年子女、三场婚礼和三场葬礼。这是 Mszana Górna 一座房屋的十一年，我的曾祖母就出自这里。

    我的家族阅读 →     1899–1909Mszana Dolna，邻近堂区
    1号的伯爵

    Krasiński 伯爵的五个孩子在 Mszana Dolna 受洗，登记的都是1号。最小的孩子由自己的兄姐担任教父母，伯爵夫人则时常给邻居的孩子当教母。

    新故事阅读 →     1901–1912Jurków、Chyszówki
    “Sipka”一词

    神父在死去的孩子名下写的一个方言词。1901年，他亲自解释了它的意思。

    摘自出版物阅读 →     1907Mszana Dolna，邻近堂区
    马戏团团长

    1907年8月20日，一名36岁的匈牙利人在 Mszana Dolna 因伤去世。神父用波兰语在括号里写下了他的职业：dyrektor cyrku（马戏团团长）。

    新故事阅读 →     1913–1925Jurków
    穿过 Jurków 的堂区边界

    1913年，Jurków 违背 Dobra 本堂神父的意愿有了自己的神父。Dobra 的本堂神父在死亡登记簿里把那些葬礼记为“未经本堂神父同意”。Jurków Dolny 至今仍属于 Dobra 堂区。

    新故事阅读 →     1914–1916邻近的 Mszana Dolna 堂区
    婚姻登记簿里的战争

    1914年2月有23对新人结婚，1915年2月一对也没有。年轻人上了战场，站到圣坛前的多是鳏夫。

    新故事阅读 →     1916Chyszówki、Półrzeczki、Jurków
    未经本堂神父同意的新墓地

    Jurków 的助理神父把 Chyszówki 的死者葬在一块未经祝圣的墓地里。Dobra 的登记簿为此写满了一整页。

    摘自出版物阅读 →     1918堂区六个村
    西班牙流感

    1918年秋，流感在 Dobra 夺走18条人命，在 Półrzeczki 夺走15条，在 Chyszówki 10条，在 Porąbka 9条。死者多是青壮年。

    如何阅读这些故事

    故事来源

    • 新故事直接根据登记簿写成，此前未见于任何书籍。
    • 摘自出版物摘自写给当地居民的出版物：《Trzy stulecia Jurkowa》（Jurków 三百年）、《Chyszówki w księgach zmarłych 1786–1926》（死亡登记簿中的 Chyszówki，1786–1926）和《Umierali w Jurkowie》（在 Jurków 逝去的人们）。
